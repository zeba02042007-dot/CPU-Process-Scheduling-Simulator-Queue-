# CPU Process Scheduling Simulator

## About the Project
This project simulates CPU process scheduling using the Queue data structure.

## Objective
To understand the working of Queue and use it to simulate CPU process scheduling.

## Data Structure Used
- Queue

## Programming Language
- Python

## How It Works
1. Add processes to the scheduling queue.
2. Processes are arranged according to the scheduling method.
3. The CPU selects a process for execution.
4. The selected process is executed.
5. The completed process is removed from the queue.
6. The process execution continues until all processes are completed.

## Example

Processes:
- P1
- P2
- P3

Execution Order:
- P1 → P2 → P3

## Time Complexity
O(n)

## Space Complexity
O(n)

## Conclusion
This project demonstrates how a Queue can be used to simulate CPU process scheduling and understand the basic working of process management.
